# LUMEN ATLAS Windows Shell

Portable Electron shell for the personal LUMEN ATLAS site.

- Loads `https://lumen.chemcraze.asia/?source=desktop`
- Keeps cookies/session in Electron's user data directory
- Allows geolocation, camera, clipboard and notification permissions
- Opens external links in the default browser
- Windows build is a portable folder containing `LUMEN ATLAS.exe`

Build (Linux or Windows):

```bash
./build-win.sh
```

The resulting zip is written to `../releases/`.
